# ⚠️ Problemas y mejoras importantes

## 1. ❌ Tailwind vía CDN (problema serio en producción)

```html
<script src="https://cdn.tailwindcss.com"></script>
```

Esto está bien para pruebas, pero en producción:

* ❌ No optimiza CSS
* ❌ Carga TODAS las clases (muy pesado)
* ❌ Peor rendimiento

### ✔ Solución profesional:

Instalar Tailwind en su proyecto Django:

```bash
npm install -D tailwindcss
npx tailwindcss init
```

Y compilarlo con purge.

---

## 2. ⚠️ JavaScript mezclado en el template

Tiene mucho JS inline:

```html
<script>
   // TODO aquí
</script>
```

### Problema:

* Difícil mantenimiento
* No reutilizable
* Mezcla responsabilidades (HTML + lógica)

### ✔ Recomendación:

Mover todo a:

```bash
static/js/app.js
```

Y cargar:

```html
<script src="{% static 'js/app.js' %}"></script>
```

---

## 7. ⚠️ Código repetido en clases Tailwind

Mucho patrón repetido:

```html

```

### ✔ Mejora:

Crear clases reutilizables en su CSS:

```css

  @apply px-3 py-2 rounded-md text-sm font-medium;
}
```
